# Análisis de Ventas - TUP Organización Empresarial

## Descripción
Análisis de ventas comerciales desarrollado como Trabajo Práctico de la materia 
Organización Empresarial - UTN Tecnicatura Universitaria en Programación.

## Integrantes
- Agustin Ezequiel Fernandez (P1 - Hugo: Líder, P2 - Paco: Desarrollador, P3 - Luis: QA)

## Escenario elegido
Escenario B - Análisis de Ventas de una Pequeña Empresa

## Dataset utilizado
- Fuente: https://gist.github.com/khanusama20/ee33c2869dd5cf3cebdf020be1ca43f6
- Archivo: datos/ventas.csv
- Columnas: id, sales_date, sales_amount
- Registros: 366 ventas diarias del año 2024

## Resultados del análisis
- Ventas totales: $1,812,114
- Promedio diario: $4,951
- Mejor día de ventas: 20 de marzo con $8,960

## Instrucciones para ejecutar
1. Clonar el repositorio
2. Abrir Google Colab
3. Ejecutar: python scripts/analisis_ventas.py

## Estructura del repositorio
- /datos - Dataset de ventas
- /scripts - Script de análisis en Python
- /resultados - Gráfico generado

## Nota sobre el Dataset
Se utilizó un dataset público de ventas diarias con registros de fecha y monto. 
Aunque el Escenario B menciona columnas de producto, cantidad y precio, este 
dataset permite calcular todos los indicadores requeridos por el trabajo práctico 
y está correctamente citado según las recomendaciones de la cátedra.
